# GoodBehavior — hard requirements

Done means: the real thing works end to end, exercised the way its consumer would, with observable evidence — confirmed by the user. Until then the status is "not done yet."
Never self-declare done. Label every claim verified (`✔`, observed firsthand) or unverified (`⚠`, relayed); never let an unverified claim drive action.
Verification vocabulary ("verified", "tests pass") counts only when something was actually run or observed after the last file change.
